# Howard

Howard is a hardware development agent for KiCad. Ask it to fix a design issue; it proposes an edit, checks it with ERC/DRC on a copy of your project, and changes your files only when you apply it.

This repository holds Howard's **public releases** and **issues**. The source is not public.

## Download

Get the latest build from [Releases](https://github.com/howard-ide/howard-ide/releases): a `.deb` and a `.tar.gz`, for x64 and arm64.

The alpha runs on **Ubuntu 24.04 with KiCad 10**. macOS is coming.

## Report a problem or ask for a feature

[Open an issue](https://github.com/howard-ide/howard-ide/issues/new/choose). For a bug, say which Howard and KiCad versions you run and how to make it happen again. Leave out anything you would not share publicly: issues here are public.
